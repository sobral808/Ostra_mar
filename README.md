# OstraCRM

Projeto inicial de CRM para colônia de pescadores de ostras.

## Estrutura

- `backend`: API em Node.js + Express
- `web`: aplicação web em React + Vite
- `mobile`: aplicação mobile em React Native / Expo
- `desktop`: aplicação desktop em Electron

## Como iniciar

### Backend
```powershell
cd C:\Users\Yulle\Documents\OstraCRM\backend
npm install
npm start
```

### Web
```powershell
cd C:\Users\Yulle\Documents\OstraCRM\web
npm install
npm run dev
```

### Mobile
```powershell
cd C:\Users\Yulle\Documents\OstraCRM\mobile
npm install
npm start
```

### Desktop
```powershell
cd C:\Users\Yulle\Documents\OstraCRM\desktop
npm install
npm start
```
